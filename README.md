# Family Hub

A modern private family messaging and social connection app for small groups of people where they can chat, post events, share photos, like, and comment on stories.

## Features
- **Family Hub Feed:** Share moments, upload pictures, like posts, and leave real-time comments.
- **Family Management:** Seamless family invitations by email or username, real-time pending requests, and instant membership.
- **Direct & Group Messaging:** Real-time messaging with conversations, unread badges, and fast chat.
- **Cross-Platform:** Runs on Web (Chrome/Safari), Android, iOS, Windows, macOS, and Linux.

## Getting Started

1. Ensure you have Flutter installed:
   ```bash
   flutter doctor
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   # On Chrome:
   flutter run -d chrome

   # On Android:
   flutter run -d android
   ```
